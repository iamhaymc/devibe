# ⏬ DEVIBE — Changes

## 0.1.0

- [x] [view] All links look like Focus links in every layout: 2.5–4 px by weight, a background outline, and the same strength, colored by kind. They no longer fade while code is read (text is drawn over links anyway). Map All links take the same smooth edge-to-edge curve as Focus instead of a folder-bundled spline that could hook at folder borders (`bundleRoute` removed). City skyways get 8 samples per span (24 at least) instead of 24 in all, so long ones stay smooth.
- [x] [view] Find is centered on the window at every width: the bar is a three-column grid whose sides share one width (the wider of the brand and the tools), so the breadcrumb shrinks before Find moves. The link directions and kind toggles moved out of the color legend into their own Links pill beside it; status stays on the right.
- [x] [view] The bar keeps only panel toggles and app buttons, in three groups: View with Fit all; Check, Selection, Change; Settings and Help. The layout switch and the Detail, Color, Height, and Links dropdowns are gone (they are in the View panel; `1`–`4`, `D`, `C`, `L` still work), and so is Open folder (the brand opens a folder, as does `O`). The new Selection toggle sits before Change: off hides the Selection panel and keeps it hidden through new selections until toggled on; on with nothing selected opens it empty so Sets can load a saved set, and its ✕ then closes it until the next selection. The choice is kept in local storage (`devibe.info`). Unused code went with it: the `picker` dropdown, `seg`'s icon-only mode, four icons, and their CSS.
- [x] [view] Symbol labels lead with a glyph instead of a word (`ƒ checkout` instead of `function checkout`): Map code labels, City roofs, the Outline, and same-named Uses and Used by rows. `ƒ` function or method, `⊕` constructor, `◆` class, `◇` interface or trait, `■` struct or record, `≡` enum, `◈` impl or extension, `τ` type alias, `{}` namespace or module, `▦` table, `▤` view, `#` heading, `•` key; unknown forms fall back by kind. Tooltips and the Selection header keep the word, and Help lists every glyph under Symbols.
- [x] [view] The bar's Detail, Color, Height (City), and Links are compact dropdowns of one form: an icon instead of the text label (the name and key are in the tooltip), then a dropdown as wide as its choice with its own chevron. Links is now a dropdown too. The group is about 330 px wide instead of 490.
- [x] [view] Open folder is in the bar, before Fit all. The View panel no longer repeats open, fit, and help, except on phones, where the bar hides them (same order as the bar).
- [x] [view] The bar has a toggle for each dock panel: View, Check, and Change. A click opens that panel and a second click closes it. Before, View options switched between View and Check, and closing View opened Check. The dock's own Check/Change tabs are now a plain title, and the toggles show at every width above phones (phones keep the bottom tabs).
- [x] [view] The Act bar is centered on the window instead of in the space between the panels. It is no wider than the free space on either side of the middle, so it never runs under the dock or Selection, and drops actions from the end to fit (More lists them all).
- [x] [view] The bar's layout switch shows icons instead of names: a treemap for Map, linked nodes for Graph, stacked tiers for Layers, a skyline for City. Each name, key, and description is in the tooltip and the accessible label; the View sheet shows icon and name (touch has no tooltips), and Help lists each layout with its icon.
- [x] [perf] The built-in parser no longer stalls on a long comment after a name: its call pattern had two `\s*` in a row, which split the masked comment's blank run every way (quadratic). `sokol_gfx.h` (1.2 MB, a 90k-character doc comment) parses in 0.2 s instead of 121 s, and a repo with the sokol headers scans in about 4 s instead of over 3 minutes. Symbols are unchanged on 218 files compared.
- [x] [scan] Max file size is a setting (Settings → Max file size, `DEVIBE_MAX_KB`, `maxKB` in `config.json`; default 2,000 KB, 1 to 100,000): files over it are listed with an estimated line count, not read. Changing it rescans every repo; files the old limit skipped are read once the new one fits them, and files over a lower one drop their cached text. With `DEVIBE_DEBUG`, the scan log counts files over the limit.
- [x] [view] Dialogs close with a ✕ in the top-right corner, and no longer close when a text selection in a field ends past the dialog's edge (as when selecting a value to paste over it): a backdrop click must start on the backdrop.
- [x] [perf] Cache and package folders (`node_modules`, `.venv`, `__pycache__`, `.next`, `.gradle`, `*.egg-info`, …) are skipped everywhere, even when committed; build output folders (`dist`, `build`, `bin`, `obj`, `target`, `vendor`, `coverage`) only when untracked. In git, untracked files are listed with both kinds excluded so git never walks into them; outside git, every `.gitignore` is honored (globs, `**`, negation, anchors, folder-only patterns, nested files). `DEVIBE_DEBUG` logs what each rule skipped.
- [x] [parsing] Optional Tree-sitter parser (`@vscode/tree-sitter-wasm`, Settings → Parser or `DEVIBE_PARSER=tree-sitter`) for C#, C/C++, Go, Java, JavaScript, PHP, Python, Ruby, Rust, TypeScript, TSX: exact symbols for macros, templates and out-of-class methods, decorators, nested lambdas, one-line interfaces, overloads, and unit structs, plus typed names and member accesses from the tree. It yields the built-in parser's shapes, so nesting, checks, and links are shared; facts are cached per parser, and switching rescans. `app/core_tree.mjs`, `test/tree.test.mjs`.
- [x] [linking] Member accesses link by the receiver's type (`_store.Find` → `IOrderStore.Find`): typed fields, parameters, locals, and constructions per language; `this`, `super`, field chains, static access; nearest declarations with lexical scoping; partial classes, impl blocks, and reopened types pooled; base types searched. External receivers (`Math.floor`, `string.Join`, `List<T>.Find`) no longer link to same-named repo functions, and names declared more than 4 times link when the receiver picks one.
- [x] [reshape] "Move only" fixes imports: JS/TS and CSS specifiers in their own form (extension, `.js` for `.ts`, folder index, aliases), Python absolute and relative modules and `import a.b` uses, and C# namespaces that follow their folder with usings and qualified names. Symbol moves carry their imports, import back what they leave behind, and retarget the files that import them; C# types land inside block namespaces. A symbol's cut takes its surrounding blank lines cleanly.
- [x] [view] Graph no longer shows the Map's boxes behind it while a large graph lays out in the worker: the parts wait as small dots at their seed places, then move into the graph.
- [x] [view] Graph links are arcs cut at the circle edges, with the arrowhead's tip on the target's edge instead of inside a circle.
- [x] [view] Layers links run from box edge to box edge, with ends that fan out toward the other box, and the arrowhead's tip on the target's edge.
- [x] [view] A→B and B→A links share one curve with an arrowhead at each end, instead of crossing into a loop.
- [x] [view] A layout switch during a running morph starts from where the tiles are, instead of jumping.
- [x] [view] Leaving City hides its glass shells: they no longer stay behind Graph, Layers, and Map as colored boxes.
- [x] [view] Map links run from box edge to box edge at right angles to both sides, instead of from box middles through folder headers; links between neighbors stay long enough to show their arrowhead.
- [x] [view] A link never ends on a part that holds its other end (a method's link into its own file now goes to the sibling it uses), and at reading zoom set and hover links end on the first line of the symbol they use.
- [x] [view] Code-line links keep beside the text: lines of one column join through a gutter bracket, and links to other files run level to the file's edge as one trunk before they curve away.
- [x] [view] All links in Map bundle where they cross folder borders, instead of detouring through folder middles.
- [x] [view] Links are thicker (2.5–4 px in Focus, by weight), opaque with a background outline, smoother (32+ points per curve), and keep full strength while code is read; arrowheads scale with the line and touch the target's edge in Map too.
- [x] [view] Bright links that run off screen are labeled where they leave with the part at their far end (→ target, ← source).
